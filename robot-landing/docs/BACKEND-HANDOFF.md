# درخواست از تیم بک‌اند: پر شدن خودکار شماره در صفحه‌ی ورود

> **وضعیت:** توافق شد — `/auth/login?phone=09121234567`.

## خلاصه
در لندینگ جدید، کاربر شماره موبایلش را همان‌جا به پیکسو می‌دهد. بعد به صفحه‌ی ورود و ثبت‌نام فرستاده می‌شود:

```
https://app.perpixai.ir/auth/login?phone=09121234567
```

**درخواست:** وقتی صفحه‌ی `/auth/login` با پارامتر `phone` باز شد، فیلد شماره موبایل خودکار با همان شماره پر شود تا کاربر لازم نباشد دوباره تایپش کند.

## جزئیات

| مورد | پیشنهاد ما |
| --- | --- |
| اسم پارامتر | `phone` |
| شکل شماره | ۱۱ رقم لاتین، با ۰۹ شروع می‌شود: `09121234567` |
| رفتار | فقط فیلد شماره پر شود. فرم خودکار ارسال نشود و کاربر خودش دکمه را بزند. |
| بعد از پر کردن | اگر در جریان شما ممکن است، فوکوس روی فیلد بعدی (رمز یا کد تأیید) برود. |
| شماره‌ی نامعتبر | نادیده گرفته شود و فیلد خالی بماند. |
| حریم خصوصی | بعد از خواندن، پارامتر از آدرس حذف شود (`history.replaceState`) تا شماره در تاریخچه‌ی مرورگر، لاگ‌ها و ابزارهای آمار نماند. |
| امنیت | مقدار پارامتر فقط برای پر کردن فیلد استفاده شود و مثل هر ورودی کاربر اعتبارسنجی شود. |

اگر اسم یا شکل دیگری برایتان راحت‌تر است، فقط بگویید؛ سمت لندینگ یک تغییر دوخطی است. مثلاً `mobile` به‌جای `phone`، یا شکل `9121234567` یا `+989121234567`.

## نمونه‌ی پیاده‌سازی (سمت فرانت صفحه‌ی ورود)

```js
const params = new URLSearchParams(location.search)
const phone = params.get('phone')
if (phone && /^09\d{9}$/.test(phone)) {
  phoneInput.value = phone // یا setState در React/Vue
  passwordInput?.focus()
}
if (params.has('phone')) {
  params.delete('phone')
  const rest = params.toString()
  history.replaceState(null, '', location.pathname + (rest ? `?${rest}` : '') + location.hash)
}
```

## تست
بعد از پیاده‌سازی، این لینک باید فیلد شماره را با `09121234567` پر کند:
https://app.perpixai.ir/auth/login?phone=09121234567

سمت لندینگ هم با `?authDebug=1` می‌شود آدرس نهایی را قبل از انتقال دید (راهنما: `docs/AUTH-TEST.md`).

## یک درخواست اختیاری
اگر برایتان مهم است بدانید چند کاربر از لندینگ آمده‌اند، می‌توانیم `utm_source=landing` را هم به لینک اضافه کنیم. لطفاً تأیید کنید که پارامترهای اضافه در صفحه‌ی ورود مشکلی ایجاد نمی‌کنند.
