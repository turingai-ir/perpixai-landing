# Project skills

Skills for building a cinematic landing page. Claude Code loads them automatically from `.claude/skills/`.
They were copied from their upstream repositories on 2026-10-22, and each one keeps its own license.

## Cinematic scroll & motion — [MengTo/skills](https://github.com/MengTo/skills) @ `398cd41` (MIT)
| Skill | Use for |
| --- | --- |
| `build-awwwards-quality-sites` | Art direction and build of Awwwards-level, motion-led sites |
| `cinematic-scroll-storytelling` | Lenis + ScrollTrigger storytelling, preloaders, sticky stacks |
| `cinematic-gsap-lenis-motion-system` | Full motion system: reveals, parallax, magnetic hovers, cursor |
| `gsap-scrolltrigger-storytelling` | Pinned product storytelling with progressive reveals |
| `scroll-scrubbed-visual-sequence` | Scroll-scrubbed video / image sequences (Apple-style) |
| `horizontal-scroll-scenes` | Scene-by-scene horizontal chapters driven by vertical scroll |
| `masked-reveal`, `staggered-word-reveal`, `scroll-scrubbed-word-reveal` | Kinetic typography reveals |
| `build-threejs-scroll-worlds` | 3D scroll-driven worlds and camera journeys |
| `add-shader-cursor-trail`, `atmosphere-background` | Shader cursor trail, atmospheric light backgrounds |
| `landing-page` | Landing-page structure, conversion and copy |
| `no-ai-design-slop` | Quality gate against generic AI-looking design |
| `optimize-web-animations` | Animation performance and memory-leak audits |
